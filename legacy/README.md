Archived files that are not part of the active runtime path live here.

- `scripts/`: old standalone experiments and one-off runners
- `scripts_wrappers/`: archived thin wrappers replaced by the unified CLI in `scripts/run_inference.py`
- `server/`: deprecated Django-side helpers and backup views
- `backend_templates/`: deprecated HTML templates kept for reference
- `backend_static/`: unused legacy UI assets
- `backend_models/`: deprecated Django models and migrations from the old product schema
- `test_data_misc/`: ad-hoc samples and scratch test data preserved from the old layout
- `utils/` and `utils_archive/`: unused helper scripts preserved for reference
- `notebooks/`: exploratory notebooks
- `logs/`: old installation or debugging logs
- `deploy/`: old deployment files and environment definitions
- `weights/`: archived checkpoints and model bundles that are not on the active path

These files are kept for reference and may require old paths or environments to run.
